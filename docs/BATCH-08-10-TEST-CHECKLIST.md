# Batch 08–10 Manual QA

- Candidate with a completed profile can apply to a published job.
- Candidate without a profile resume must upload PDF/DOC/DOCX; max 5 MB.
- Candidate with a saved profile resume can apply without uploading another file.
- Duplicate application is blocked; candidate sees current application status on job detail.
- Candidate sees own applications and can withdraw only a newly submitted application.
- Candidate can save and remove a published job; duplicate saves are prevented by a unique key.
- Employer sees applicants only for jobs owned by the employer's company.
- Employer can filter applicants by status and move an application through review statuses.
- Candidate cannot access employer applicant routes; employer cannot access candidate routes.
- Deleting a job/user cascades related application and saved-job records.
